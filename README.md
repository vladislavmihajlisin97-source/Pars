# Pars — парсер телеграм-каналів

Головна функція: **повністю спарсити вміст телеграм-каналу** — усі повідомлення,
медіа, реакції, перегляди, відповіді та форварди — і зберегти все у структурованому
вигляді (JSON / JSONL / CSV) з опційним завантаженням файлів медіа.

## Можливості

- 📜 **Повна історія каналу** — від першого до останнього повідомлення (або за фільтрами:
  ліміт, діапазон id, період дат)
- 🖼️ **Медіа** — фото, відео, голосові, аудіо, документи, стікери, GIF, відео-кружечки;
  паралельне завантаження, дедуплікація, пропуск уже завантаженого (докачування після обриву)
- 📊 **Метадані повідомлень** — перегляди, форварди, реакції (по емодзі), автор (підпис),
  групування в альбоми, редагування, посилання на пост
- 📤 **Три формати виводу** — JSON (самодостатній), JSONL (потоковий), CSV (для Excel/табличок)
- 🔓 **Два режими**:
  - `api` *(основний)* — через офіційний MTProto API (Telethon): повний вміст,
    включно з приватними каналами, де ви є підписником
  - `web` — через публічну веб-превʼюшку `t.me/s/<канал>` **без жодних ключів**
    (лише публічні канали, лише те, що видно у превʼю)

## Швидкий старт

```bash
# 1. Встановлення
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Ключі API (один раз): https://my.telegram.org -> API development tools
cp .env.example .env               # потім впишіть туди api_id та api_hash

# 3. Перший вхід (телефон + код з Telegram; збережеться у pars.session)
python pars.py login

# 4. Парсимо весь канал
python pars.py parse durov
```

Результат зʼявиться у `output/durov/`.

## Приклади

```bash
# весь вміст каналу + усі медіа, у трьох форматах
python pars.py parse @durov --media --format all

# лише останні 500 повідомлень, з фото та відео, до 200 МБ на файл
python pars.py parse https://t.me/durov -l 500 --media \
    --media-types photo,video --max-media-size 200

# повідомлення за періодом, від старих до нових
python pars.py parse durov --since 2024-01-01 --until 2024-06-30 --reverse

# докачати історію з певного повідомлення (id > 1000)
python pars.py parse durov --min-id 1000

# все до конкретного поста (id <= 5000)
python pars.py parse durov --max-id 5000

# інформація про канал (назва, опис, к-сть підписників)
python pars.py info durov

# БЕЗ ключів і входу: публічна превʼюшка t.me/s (текст, дати, перегляди)
python pars.py parse durov --mode web
```

## Режими

### `api` (типовий) — повний вміст

Використовує MTProto API через бібліотеку [Telethon](https://docs.telethon.dev).
Потрібні `api_id`/`api_hash` (безкоштовні, [my.telegram.org](https://my.telegram.org))
та одноразовий вхід (`pars.py login`) — далі сесія живе у файлі `pars.session`.

Дає: **усі** повідомлення (включно з дуже старими), повні метадані, реакції по
окремих емодзі, завантаження медіа в оригінальній якості, доступ до приватних
каналів і чатів, де ваш акаунт є учасником.

### `web` — без ключів

Зчитує публічні сторінки `https://t.me/s/<канал>` (тільки-лише читання, без Telegram-акаунта).
Підходить для швидкого огляду публічних каналів: текст, дати, перегляди, превʼю медіа.
Обмеження: немає реакцій по окремих емодзі, превʼю медіа стиснуті (~320px), якщо
у каналу вимкнено веб-превʼю — режим не працюватиме (скрипт підкаже перейти на `api`).

## Довідка команд

```
python pars.py parse КАНАЛ [опції]

КАНАЛ                  @username, username, https://t.me/username,
                       https://t.me/username/123 або числовий id
-m,  --mode            api | web                    (типово: api)
-l,  --limit N         максимум N останніх повідомлень (0 = усі)
     --min-id ID       повідомлення з id > ID
     --max-id ID       повідомлення з id <= ID
     --since DATE      від дати (YYYY-MM-DD або ISO 8601)
     --until DATE      до дати
     --reverse         від старих до нових
-o,  --out DIR         кореневий каталог результатів (типово: output)
-f,  --format          json | jsonl | csv | all    (типово: json)
     --media           завантажити медіа
     --media-types     фільтр: photo,video,voice,audio,document,sticker,gif,video_note
     --max-media-size  ліміт розміру файлу, МБ (0 = без обмеження)
     --media-workers N паралельні завантаження (типово: 4)
     --session NAME    назва файлу сесії (типово: pars)
```

Також: `python pars.py info КАНАЛ` — інформація про канал; `python pars.py login` —
створити сесію.

## Конфігурація

Ключі беруться зі змінних оточення або з файлу `.env` (зразок — `.env.example`):

| Змінна              | Опис                                        |
|---------------------|---------------------------------------------|
| `TELEGRAM_API_ID`   | api_id з my.telegram.org                    |
| `TELEGRAM_API_HASH` | api_hash з my.telegram.org                  |
| `TELEGRAM_SESSION`  | назва файлу сесії (типово `pars`)           |
| `TELEGRAM_PROXY`    | проксі, напр. `socks5://127.0.0.1:9050`     |

## Нотатки й обмеження

- **Аккаунт має бачити канал**: щоб спарсити приватний канал/чат, ваш акаунт
  має бути його підписником/учасником. Telegram не віддає вміст «чужих» приватних каналів.
- **Посилання-запрошення** (`t.me/+...`) не розвʼязуються напряму — спочатку
  приєднайтесь до каналу, потім парсіть за `@username` або числовим id.
- **Числовий id** приватного каналу працює, лише якщо ця сесія раніше «бачила» канал.
- **Flood-limits**: Telethon сам долює короткі flood-wait; завантаження медіа йде
  пулом у 4 паралельні задачі. Для великих каналів (~100k+ постів) просто дайте
  скрипту час або використовуйте `--limit` / `--min-id` для докачування частинами.
- **Сесія = доступ до акаунта**: `*.session` нікуди не передавайте і не комітьте
  (він уже у `.gitignore`).
- Це інструмент для роботи з *доступним вам* контентом — поважайте авторські права
  та умови використання Telegram.
